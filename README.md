# 💻 Algoritmos e Programação de Computadores (TADS)

Bem-vindo(a) ao meu repositório de práticas e atividades da disciplina de **Algoritmos e Programação de Computadores**, do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS).

O objetivo deste espaço é centralizar todos os exercícios, desafios e projetos desenvolvidos ao longo do semestre, servindo como um histórico do meu aprendizado e evolução na lógica de programação.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

*   **Linguagem principal:** C++
*   **Ambiente de Desenvolvimento (IDE):** Online C
---

## 📁 Estrutura do Repositorio

O repositório está organizado de forma a facilitar a navegação pelas semanas de aula ou tópicos estudados:

*   `🔬 Exercicios-Fixacao/`: Pequenos problemas resolvidos para fixar a lógica.
*   `📝 Trabalhos/`: Projetos e atividades avaliativas da disciplina.
*   `💡 Desafios/`: Códigos extras ou desafios propostos pelo professor.

## 🎯 Principais Conceitos Praticados

Até o momento, o repositório engloba práticas sobre:
- [ ] Lógica de programação básica e variáveis
- [ ] Estruturas condicionais (`if`, `else`, `switch`)
- [ ] Estruturas de repetição (`while`, `for`, `do-while`)
